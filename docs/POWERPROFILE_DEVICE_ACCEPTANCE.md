## 遇到的问题与修正

- 手机首次 APK 安装要求系统指纹；由用户本人完成后安装成功。ADB 不代替安全验证。
- 安装期间 AstroBox 出现原生 SIGABRT / Rust IPC panic，两次队列记录丢失。后来系统反复请求目标手环蓝牙配对；手机侧确认后，用户在手环完成确认，恢复连接并看到数据。尚不能断言配对等待是原生崩溃的根因，也不能把 AstroBox 崩溃写成已由本项目修复。
- 初版手机只要读到电脑快照就显示“统计已同步”，无法区分设备是否收到。现在改为“电脑统计已读取”，手环成功应用数据后单独回执，再显示“手环已应用统计快照”。电脑持久记录白名单字段：事件类型、快照时间、设备版本码、电脑接收时间，不保存聊天内容。
- 增加“10 秒后发送测试提醒”，通过生产同一通知渠道发布明确标记的测试消息。留出锁屏时间；诊断消息不进入 Codex 完成事件队列、不生成完成 ACK，也不等同于所有真实任务来源已覆盖。
