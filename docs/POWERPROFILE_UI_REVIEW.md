# PowerProfile 手环 UI 审阅与发布

2026-11-19 用户已审阅可交互预览，明确批准“ok，就按这个做远程ota吧”。此前仅本地审阅的暂停标记已经归档为 approved；旧 v14 清单仍作为 pre-ui-review 留档，新包重新构建、审计和签名。

## 已批准的界面

原创电源环应用图标和离线 PNG；336×480 黑色紧凑卡片布局；电脑主指标、用电/游戏双列、AI Token 单行和双额度合并卡片；同步/更新放在下方。估算用电保留标识，未知为破折号，缓存和过期额度保留旧值说明。

电脑卡片右侧为无额外文字的电源图标按钮。时长不再加“时:分”，Codex 重置显示“X小时X分后重置”或“X天X小时后重置”。电源按钮显示插座实际读回供电状态，不能以统计上传或电脑在线状态推断插座状态。

## 控制路线

用户先提出复用 Windows 米家中枢，后明确改为手机直连米家云端，让电脑离线后仍可恢复插座供电。电脑侧现有中枢与凭据不改动。见 [米家云端设计与测试边界](./POWERPROFILE_MIJIA.md)。本轮只测试空气净化器，测试后恢复原状态；不切换电脑插座。
